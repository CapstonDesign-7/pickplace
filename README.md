# PickPlace
---
## 구현한 기능
- 회원가입 및 로그인(JWT)
- 일정 작성(상세 스케줄 및 랜덤, 경로짜기는 미구현)
- 포토 리뷰 작성(본인의 일정이 존재해야 함) 및 목록 보여주기 => 일정에서 선택한 장소를 키로 공유
- 좋아요 기능
- 타입별 검색 기능(제목, 지역) => 검색어에 해당 문자가 있으면 검색됨.
- 사용자 프로필(이름, 전화번호, 이메일 및 비밀번호 변경 기능)
- 이메일로 아이디 및 비밀번호 찾기 기능(우선 Gmail만)
